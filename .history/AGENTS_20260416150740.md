# 微信小程序 - 时光记·日记目标打卡本 开发智能助手指南

## 一、项目基础信息（AI必看）

- **项目名称**：时光记·日记目标打卡本
- **开发环境**：微信原生小程序（WXML + WXSS + JS + JSON），无跨端框架
- **设计资产**：Figma/Figma Make 已完成原型+UI设计（开发需1:1还原）
- **核心定位**：轻量化「日历日记+目标管理+每日打卡」一体化工具，以日历为核心入口，实现日记与目标打卡的联动
- **核心功能**：月日历图文日记、年/月/周/日四级目标管理、每日打卡、数据统计、本地存储

## 二、AI角色定位与行为准则

### 2.1 角色定位

作为本微信原生小程序专属开发助手，专注于提供可直接运行、无报错、符合项目规范的微信原生代码，不涉及任何无关技术方案。

### 2.2 强制行为准则

- 严格遵循微信原生小程序语法，禁止提供uni-app、Taro、Vue、React等跨端框架代码；
- 代码需带完整注释，变量名、方法名通俗易懂，保持统一规范；
- 严格按照本文档的页面结构、数据结构、UI规范开发，不擅自修改需求或简化功能；
- 优先实现核心功能，兼顾代码简洁性和可维护性，适配微信小程序所有主流机型；
- 所有功能基于微信本地存储（wx.setStorage/wx.getStorage）开发，实现离线优先。

## 三、技术栈与开发规范

### 3.1 技术栈（固定不变）

- 结构层：WXML（微信原生标记语言）
- 样式层：WXSS（支持rpx、flex布局、微信内置样式）
- 逻辑层：JavaScript（ES6标准）
- 配置层：JSON（全局配置、页面配置）
- 存储层：微信小程序本地缓存（无后端依赖）

### 3.2 目录结构规范（固定）

```

{
  "/pages": {
    "index": "首页 - 月日历视图",
    "detail": "当日详情页 - 打卡+日记编辑",
    "target": "目标管理页 - 年/月/周目标",
    "stats": "统计页 - 打卡数据可视化",
    "mine": "我的页 - 设置与数据管理"
  },
  "/utils": "工具函数（日期处理、本地存储、数据统计）",
  "/components": "自定义组件（日历、打卡项、图片上传）",
  "app.js": "全局逻辑",
  "app.json": "全局配置",
  "app.wxss": "全局样式"
}
    
```

### 3.3 通用开发规范

- 尺寸单位：统一使用rpx，适配所有手机机型；
- 颜色规范：直接使用Figma设计稿中的十六进制色值，不自行修改；
- 间距规范：页面左右边距32rpx，模块间距24rpx，元素内边距统一；
- 字体规范：标题18-20rpx（font-weight: 500/600），正文14-16rpx（常规），字体统一使用微信系统默认字体；
- 组件规范：拆分3个核心自定义组件（calendar、todo-item、image-picker），组件可复用、低耦合。

## 四、核心页面结构与开发要求

### 4.1 首页 /pages/index（主入口）

**功能**：月日历视图展示、日期状态标记、快速操作入口

**必须包含元素**：

- 顶部：APP名称/Logo、搜索图标、设置图标；
- 年月切换栏：居中显示当前年月，左右箭头切换上下月；
- 月日历网格：7列（星期：一至日），最多6行，日期格子宽高相等；
- 日期状态标记：当天高亮底色、有日记显示🖋图标、已打卡显示✅图标、有未完成目标显示小圆点；
- 底部：当日简要预览卡片（今日待办数量、日记有无）、悬浮快速添加按钮（+）。
- 日历上需要显示法定节假日和24节气信息。

**交互要求**：

- 点击任意日期 → 跳转至/detail页面，携带当前日期参数；
- 左右滑动日历网格 → 切换月份；
- 长按日期 → 弹出操作菜单（写日记、快速打卡）；
- 点击底部预览卡片 → 跳转至今日详情页；
- 点击悬浮按钮 → 跳转至今日详情页并聚焦日记编辑区。

### 4.2 当日详情页 /pages/detail（核心页面）

**功能**：当日目标打卡、图文日记编辑与保存

**必须包含元素**：

- 顶部：当前日期（格式：2026-03-30 周一）、更多按钮（…），点击显示分享/删除/导出选项；
- 目标打卡区（上半区）：标题栏（今日待办 + 展开/收起箭头）、待办列表（圆形打卡框+目标内容+来源）、添加临时任务按钮；
- 日记编辑区（下半区）：标题输入框、多行文本编辑框、横向图片列表（+添加图片按钮）、心情/标签选择（开心/平静/疲惫/努力等）；
- 底部：自动保存提示、完成按钮（收起键盘）。

**交互要求**：

- 点击圆形打卡框 → 切换打卡/未打卡状态，同步更新日历标记；
- 左滑待办项 → 显示编辑/删除选项；
- 点击图片 → 预览图片，预览页支持删除；
- 点击+添加图片 → 弹出图片选择器（拍照/相册）；
- 输入内容时自动保存，页面卸载时再次校验保存；
- 点击展开/收起箭头 → 切换打卡区显示状态，收起后日记区全屏展示。

### 4.3 目标管理页 /pages/target

**功能**：年/月/周三级目标的创建、编辑、删除

**必须包含元素**：

- 顶部Tab切换栏：年目标、月目标、周目标；
- 目标卡片列表：每个卡片包含标题、进度条、完成率、时间范围、下级目标数量；
- 底部悬浮按钮：+ 添加对应层级目标（切换Tab时按钮功能同步切换）。

**交互要求**：

- 点击Tab → 切换目标层级，刷新卡片列表；
- 点击目标卡片 → 进入目标详情页；
- 左滑目标卡片 → 显示编辑/删除/完成选项；
- 点击目标卡片内的“拆解”选项 → 自动创建下级目标（年→月、月→周、周→每日待办）；
- 点击底部+按钮 → 弹出目标创建弹窗。

### 4.4 统计页 /pages/stats

**功能**：打卡数据、日记数据可视化展示

**必须包含元素**：

- 顶部统计概览：连续打卡天数、本月目标完成率、总日记数量；
- 月度打卡热力图：GitHub风格，以色块深浅表示打卡活跃度；
- 数据图表：目标完成率环形图、每周/每月完成趋势图；
- 辅助统计：目标完成排行、日记数量月度统计。

**交互要求**：

- 点击热力图日期 → 跳转至对应日期详情页；
- 左右滑动图表 → 切换不同月份/周的数据；
- 点击目标排行 → 进入对应目标详情页。

### 4.5 我的页 /pages/mine

**功能**：用户设置、清除缓存等

**必须包含元素**：

- 用户信息区：头像、昵称；
- 功能菜单：用户设置、清除缓存；
- 底部：版本号、免责声明（可选）。

**交互要求**：

- 点击日记加密 → 设置密码/指纹，加密后进入日记需验证；
- 点击主题切换 → 切换预设主题（对应Figma设计稿）；
- 点击数据导出 → 导出日记/打卡数据（支持PDF/图片格式）；
- 点击清除缓存 → 弹出确认弹窗，清除本地缓存（保留核心数据）。

### 4.6 通用弹窗组件

- 新建日记弹窗：快速输入标题+简短内容、添加图片；
- 快速打卡弹窗：选择目标、一键完成打卡；
- 日期选择器：快速跳转到指定日期；
- 图片选择器：拍照/相册多选、预览；
- 删除确认弹窗：删除日记/目标/图片时的二次确认。

## 五、核心数据结构（严格遵循）

### 5.1 日记数据结构

```

{
  date: "2026-03-30",        // 日期（主键，格式：YYYY-MM-DD）
  title: "今日心情",          // 日记标题（可选）
  content: "日记内容文字",    // 日记正文（多行文本）
  images: ["图片路径1", "图片路径2"], // 图片数组（本地临时路径/Base64）
  mood: "开心",              // 心情标签（可选，对应设计稿选项）
  createTime: 1711708800000, // 创建时间戳
  updateTime: 1711709800000  // 更新时间戳
}
    
```

### 5.2 目标数据结构

```

{
  id: "1711708800000",       // 唯一ID（时间戳生成）
  type: "year",              // 目标类型：year/month/week
  title: "2026年阅读50本书",  // 目标标题
  startTime: "2026-01-01",   // 开始日期（YYYY-MM-DD）
  endTime: "2026-12-31",     // 结束日期（YYYY-MM-DD）
  progress: 0.6,             // 完成进度（0-1）
  checkList: ["2026-03-30", "2026-03-31"], // 已打卡日期数组
  todoList: [                // 每日待办列表（仅周目标有）
    { 
      date: "2026-03-30",    // 待办日期
      content: "阅读30分钟",  // 待办内容
      done: true             // 是否完成
    }
  ],
  parentId: "",              // 父目标ID（月目标对应年目标ID，周目标对应月目标ID）
  isCompleted: false         // 是否整体完成
}
    
```

### 5.3 打卡记录数据结构

```

{
  date: "2026-03-30",        // 日期（主键）
  targetIds: ["1711708800000", "1711709000000"], // 当日已打卡目标ID数组
  doneCount: 2,              // 当日完成打卡数量
  totalCount: 3              // 当日总待办数量
}
    
```

## 九、补充说明

- 所有页面跳转需使用微信小程序原生路由（wx.navigateTo、wx.switchTab等），跳转时携带必要参数；
- 本地存储需做数据校验，防止数据丢失或错乱，关键数据（日记、目标）需做备份；
- 图片上传后先存储本地临时路径，再转为Base64或永久路径，确保页面刷新后图片不丢失；
- 所有交互需有明确反馈（如点击按钮变色、打卡成功提示），提升用户体验；
- 严格按照Figma设计稿的布局、间距、字体、颜色开发，不擅自调整UI细节。
